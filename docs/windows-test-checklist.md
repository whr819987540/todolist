# Windows 上的测试清单（2026-10 这一批功能）

这批功能（正文查找 / 替换、全文搜索、大纲、开机自启、快速记录、置顶、手动排序、批量操作、回收站）在 Linux 上开发，之后在 Windows 上逐项实测过。能自动化的都写成了端到端测试（`npm run e2e`，每次 push 后 GitHub Actions 也会在 Windows 机器上跑，见 README.md 的「端到端测试（Windows）」），下面先列它覆盖了什么，再列它测不到、要手动试的。

## 端到端测试覆盖的（`e2e/suites/`）

- `find`：Ctrl+F 打开查找框（焦点在正文、标题、左侧列表时都行；没打开待办时聚焦侧栏搜索框，首页聚焦首页搜索框），第几个 / 共几个，Enter / Shift+Enter / F3 / Shift+F3，到末尾从头找，区分大小写、全字匹配、正则（写错时「正则有误」），输入法组合中不查，Ctrl+H 替换 / 全部替换和撤销，Esc 关闭，选中的文字（一行以内）拿来查、跨行的不拿，接着用上次的内容（切到别的待办也是），带反斜杠的按原样查，查找框没开着时 F3，外部修改重新加载后查找框还开着，只读的正文没有替换
- `search`：侧栏、首页的全文搜索（正文后部的词、关键字附近的一段、高亮），不区分大小写，GBK 编码的正文，保存后、外部修改后按新内容搜，Esc 清空回到列表，点首页的结果打开待办，回收站里的搜不到
- `outline`：标题列表（去掉标记、按级别缩进、代码块里的 # 不算），点标题跳过去，正在看的那一节高亮（光标在可见区域里时按光标），打字后更新，Ctrl+Shift+1 和状态栏切换、本机记住，1 个标题时不显示，编辑区不到 700px 时不显示
- `autostart`：设置里的开关 ↔ 注册表 Run（带引号的路径加 `--autostart`），任务管理器里禁用（StartupApproved）后显示关闭、在软件里打开改回启用，关闭时两处都删，不碰安装版的启动项，开没开不写进设置文件（单元测试 `autostart::tests::registry_follows_task_manager_state` 也在 CI 上测注册表读写）
- `startup`：带 `--autostart` 启动时只在托盘里（上次最大化的也不弹出来），一直没打开就退出、下次正常打开仍是最大化，第一次显示时恢复最大化，取消「只在托盘里」后开机显示主窗口
- `quick`：快捷键弹出小窗（在前台、输入框有焦点），不在任务栏和 Alt+Tab 里，默认存到「收件箱 / 快速记录」（注明保存时新建），Shift+Enter 换行，输入法组合中的 Enter，Enter 保存（第一行标题、其余正文），主窗口刷新，草稿，Esc / 再按快捷键 / 失去焦点时藏起来，Ctrl+Enter 和「保存并打开」（主窗口在首页、在别的工作区、藏在托盘里时都弹到前台并打开），换存到的项目、改名移动后跟着变，设置「常规」里显示和修改，深色主题，刚启动时按快捷键
- `shortcuts`：「快速记录」在全局快捷键一组，录制时暂停全部全局快捷键，和别的快捷键重复、被别的程序占用时提示，修改、恢复默认、不使用，以前把别的快捷键设成 Ctrl+Alt+N 的设置文件，编辑快捷键录制 Ctrl+F / Ctrl+H 时提示被占用、固定按键里列出查找和替换
- `pin`：右键置顶 / 取消置顶，修改时间不变，各种排序下都在最前，已完成的置顶排在已完成里最前，项目概览，移到别的项目后仍置顶
- `reorder`：左侧列表和项目概览里拖动调整顺序（插入线、说明、上半截 / 下半截），改为手动排序的提示，修改时间不变，已完成和未完成、置顶和没置顶不能混排，搜索时不能调，新建的排最前，拖到别的项目照常是移动，重新打开后顺序不变
- `batch`：Ctrl / Shift+单击（跨项目、跨工作区），批量完成 / 未完成 / 置顶 / 移动 / 删除，按工作区分组的「移动到」，右键批量菜单，Esc（菜单开着时只关菜单），Ctrl+Alt+D，Delete 先确认、一次撤销恢复全部，普通单击、方向键、返回首页取消多选，一起拖到别的项目、右侧不闪「待办不存在」，部分失败的提示，外部删掉一条后 F5
- `recycle`：删除待办 / 项目 / 工作区进 `.recycle`，撤销（打开着的重新打开、工作区回到侧栏），回收站不当成工作区、搜不到，首页和侧栏底部的回收站（最近删除的在前、查找、恢复时标题 / 完成 / 置顶 / 创建时间都在），原来的项目不在了重新建、名字被占用加「（恢复）」，彻底删除和清空移到 Windows 回收站（名字是「标题（id）」）、从那里还原后还能恢复，放满 30 天的启动后移走、还原回来的不会再被移走，文件被占用时删除待办 / 项目失败、原样不动
- `hidedone`：「隐藏已完成」菜单里的「隐藏全部完成的项目」，空项目照常显示，「已隐藏 N 个全部完成的项目，显示」，记在本机，经标签 / 工作区概览打开时照常显示、切走 1 秒后藏起来（刚切走时还在；看着它时双击它下面项目里的待办 / 双击它下面的项目，固定 / 折叠的是双击的那个），搜索时不藏，「全部折叠 / 全部展开」不算藏起来的（手动折叠完看得见的项目后是「全部展开」，点了连藏起来的一起折叠，正在看的、切走后还在显示的算）、不算折叠着的工作区里的（折叠工作区后是「全部展开」，点了工作区也展开），改回未完成后又显示，点「显示」关掉，和「隐藏已完成的待办」一起开
- `subprojects`：右键项目「新建子项目」（子项目的菜单里没有），拖动项目到别的项目上放进去成为子项目（说明、高亮），有子项目的拖到别的项目上标红、放不下，右键子项目「移动到 → 顶层」移出来，建成项目文件夹里的子文件夹，侧栏里缩进列在父项目下面、它自己的待办前面，在子项目概览里快速添加，父项目行上的未完成数和父项目概览（子项目卡片、「含子项目」的数目）包括子项目，编辑区上方和标签写成「工作区 / 父项目 / 子项目」，子项目上按 ← 先折叠再回到父项目，在项目文件夹里建的文件夹刷新后是子项目，父项目改名后子项目和打开着的待办跟着，隐藏全部完成的项目时全部完成的子项目单独藏、父项目还在，删除子项目和撤销，首页搜索按子项目名找到
- `tabs`：单击打开在预览标签里、再单击别的替换它，双击左侧的待办 / 标签、修改正文后固定，新开的在正显示着的右边；点标签切回来时选区、滚动、光标在屏幕上的位置都和离开时一样，焦点在正文里，还能撤销；切走时保存；有没保存的修改时标签上的圆点（切走、Ctrl+S 后没了）；Ctrl+Tab / Ctrl+Shift+Tab（到头了从另一头接着），焦点在右侧时 Alt+← / Alt+→ 切标签（连着按、最左边回到左侧列表、最右边 / 标题上把焦点放进正文，点了侧栏底部的统计后 Alt+← 回到左侧列表）和 Alt+↑ 关标签（按住只关一个，关掉最后一个后左侧的选中项不动），Ctrl+W、鼠标中键、右键「关闭其他标签」，拖动标签调整顺序（放在前面 / 后面、拖动没显示着的标签不切换、Esc 取消），关掉正显示着的切到右边 / 左边的，都关掉了显示项目；显示概览时标签仍在；记在 `.state.json`、重启后还在；外部删掉的待办刷新后关掉标签
- `backup`：启动后自动备份到数据目录旁边的 `data-backups`（备份里有说明 `backup.json`、空的工作区、待办正文，没有设置文件），设置里显示上次自动备份的时间和份数、默认的备份目录；手动备份到本地（「另存为」对话框在页面里换成直接返回路径）的提示（完整路径、几个工作区几条待办），备份里有项目里的 `.assets`、`.todos.json`、`.state.json`，没有回收站、临时文件、设置文件，不能存到数据目录里面；恢复设置时选了数据备份、恢复数据时选了设置备份的提示，zip 里有 `../` 时整个不恢复；恢复前的确认（备份时间、几个工作区几条待办、替换全部、先备份到哪里），恢复后整页重新加载回到首页、提示恢复了什么，后来建的工作区不在了、正文和附件换回来、修改时间不变、回收站不动，正在编辑没保存的先存盘、进了 `…-恢复前.zip`（不算自动备份），内存里的标签没有在稍后覆盖恢复出来的 `.state.json`，快速记录小窗再弹出时列出恢复后的项目；保留份数存在设置文件里，满 24 小时但数据和最新的一份一样时跳过（设置里说明），数据变了就备份、只留最近 N 份、恢复前的那份不删，换备份目录时不能选在数据目录里面，目录建不起来时不弹窗、设置里写明原因，恢复默认的目录，关掉自动备份
- `history`：首页头部和侧栏底部的「完成记录」，按完成日期分组（今天、昨天、「10月7日 星期三」，组名后面的条数，组里后完成的在前），每条的标题 / 正文开头、「工作区 / 父项目 / 子项目」、几点几分，最近 7 天里没有 10 天前的和没有完成时间的，最近 30 天、「全部」（最后的「完成时间不详」，不画柱状图），统计和柱状图的每天条数、悬停提示，按项目 / 标题（不区分大小写）查找、找不到时的说明，时间范围关掉再开、重新加载后还在，右键「标记为未完成」（`.todos.json`、首页卡片跟着变），点一条进入工作区打开在预览标签里、左侧选中它，侧栏里默认看选中的工作区、切到「全部工作区」，开着时外部标记完成、删除进回收站后窗口获得焦点跟着更新，点没选中的工作区里的一条时选中它，行上的按钮「标记为未完成」后侧栏的勾选框跟着取消

## 要手动试的

测试版的构建和运行方法见 README.md 的「本机测试用的构建」（换 identifier 和产品名、数据放临时目录）。

- [ ] 开机自启：打开开关后真的注销 / 重启，登录后只有托盘图标、没有弹出主窗口；取消「只在托盘里」后登录时显示主窗口
- [ ] 启动时没有白屏闪一下、窗口跳位置（主窗口一开始是隐藏的，在 setup 里恢复大小位置后才显示）
- [ ] 安装版：卸载后注册表 Run 里的启动项被删掉；`npm run release -- patch` 升级（/UPDATE）后启动项还在（Tauri 的 NSIS 模板只在不是升级时 `DeleteRegValue HKCU ...\Run "${PRODUCTNAME}"`）
- [ ] 快速记录：多显示器时在鼠标所在的屏幕上弹出；标题处可以拖动小窗；用真实的中文输入法在小窗里打字，组合中按 Enter 只上屏；按 Alt+Tab 时列表里没有「快速记录」
- [ ] 托盘：右键菜单有「快速记录」，点了弹出小窗；左键单击托盘图标显示主窗口（开机自启只在托盘里、上次最大化时，显示出来是最大化的）
- [ ] 在别的程序里按真实的 Ctrl+Alt+N / Ctrl+Alt+T（端到端测试是直接发 WM_HOTKEY，不经过键盘）
- [ ] 正文里查找：用真实的中文输入法在查找框里打字
- [ ] 标签页：用真实的鼠标中键关标签（不出现自动滚动的图标）；标签多到放不下时用滚轮横着滚动标签栏，切到的标签自动滚到看得见的地方；用真实的中文输入法在预览标签的正文里打字，上屏后标签固定下来
- [ ] 数据多（几千条）时的搜索速度：本机 debug 构建 3000 条、14 MB 正文，第一次查约 0.5 秒，之后约 20 毫秒，常见词（2000 条命中）约 80 毫秒
- [ ] 删除时项目文件夹开在资源管理器里（一般不会占用，删除照常成功）
- [ ] 设置备份到本地 / WebDAV 再恢复：快速记录的快捷键、存到哪里、开机自启时是否显示主窗口跟着恢复（开机自启本身不随备份）；自动备份的开关、目录、份数、是否上传 WebDAV 也跟着恢复
- [ ] 待办数据备份到 WebDAV（坚果云）：「备份数据到 WebDAV」后列表里出现标着「数据」的一项，点「恢复」确认后恢复、界面重新加载；打开「同时上传到 WebDAV」后自动备份也上传，远程目录里的数据备份只留最近 N 份，设置备份不删；密码错了、断网时自动备份照样存在本地，设置里写明上传失败的原因（单元测试里是本机起的假 WebDAV 服务器）
- [ ] 真的对话框：「备份数据到本地…」的「另存为」从备份目录打开、默认文件名 `TodoList-data-年月日-时分秒.zip`、同名要确认才覆盖，存到数据目录里面时提示；「从本地文件恢复数据…」从备份目录打开；「更改…」选文件夹（端到端测试里这些对话框换成了直接返回路径）
- [ ] 数据多（几千条、项目里放几百 MB 的附件）时：备份数据时按钮显示「正在备份…」，期间界面照常能用、能编辑保存；恢复要等一会儿，确认框的「恢复」按钮转圈
- [ ] 藏在托盘里过一夜（或把系统时间往后调一天多）：自动备份照常做了一份；没改过数据时不再多一份
- [ ] 恢复时有文件正被别的程序占用（如用别的编辑器打开着待办、资源管理器开着预览）：提示恢复失败和原因，数据没变；关掉占用的程序后再恢复成功
- [ ] 用资源管理器打开备份 zip：中文的工作区、项目名正常，能直接解压出来看
- [ ] 完成记录在浅色、深色主题下的样子：柱状图（主色的柱子、基线、最多那天的条数、日期）、悬停柱子的提示、滚动时停在顶上的组名、悬停一行才出现的「标记为未完成」；侧栏窄（240px）时底部的统计换行、「完成记录」「回收站」不被挤掉
- [ ] 完成记录开着跨过零点（或把系统时间往后调到第二天）：「今天」变成「昨天」，最近 7 天的范围和柱状图往后挪一天
- [ ] 完成记录里用键盘 Tab 到柱子上：显示和悬停时一样的提示，Enter 跳到那天的组；30 天时点较早的一根，列表滚到那天
- [ ] 已完成的待办多（几千条）时：完成记录选「全部」打开、滚动、查找不卡
- [ ] 数据目录用网盘同步时恢复数据：网盘客户端占着文件时的提示；恢复后网盘同步过去的是恢复出来的数据
- [ ] 导出的真的「另存为」对话框：第一次从「文档」打开、之后从上次导出到的目录打开；默认文件名是待办的标题（没有标题时正文开头）、项目名（子项目是「父项目 - 子项目」）、工作区名，标题里有 `/ : ?` 这些字符时换成了「_」；同名文件要确认才覆盖；只输入文件名不带扩展名时补上 .html（端到端测试里对话框换成了直接返回路径）
- [ ] 导出完的提示里点「打开」用默认浏览器打开导出的 HTML，点「在文件夹中显示」在资源管理器里选中它
- [ ] 导出的 HTML 拷到别的电脑（或删掉原来的数据后）用 Edge / Chrome 打开：本地图片照样显示，中文字体、浅色、A4 宽度居中，深色模式的浏览器里也是浅色；表格、代码块、任务框、提示块（`> [!NOTE]`）、脚注的样子，点目录跳到对应的一节、点脚注跳过去再跳回来
