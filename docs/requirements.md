# 软件要求

待办清单要做成什么样。加功能、改功能时先改这里（和 README.md）；单元测试、端到端测试的用例按这里写的行为写，不照着实现抄期望值。

## 基础

- 提供工作区、项目、项目下某个todo item三级划分
- 项目下可以建子项目：只有一层，子项目里不能再建子项目；父项目自己也能直接放待办。子项目存成项目文件夹里的子文件夹（`{工作区}\{项目}\{子项目}`），在资源管理器里也能看到层级；用户直接在项目文件夹里建的文件夹同样算子项目（子项目里的文件夹不算）。同一个项目里的子项目不能重名（不分大小写），不同项目里的可以
- 暂时只支持windows版本，所有数据存储到用户的家目录
- 界面状态里和数据有关的（选中的工作区、上次的位置、各工作区上次打开的待办、右侧标签页里打开着的待办、各待办的编辑位置和编辑模式）存在数据目录的 `.state.json`，跟着数据走：换电脑、重装系统、卸载时删除应用数据都不会丢，数据目录用网盘同步时一起同步。改动后稍后（5 秒内）写盘，隐藏到托盘、退出前立即写；以前记在本机的，第一次启动时搬过去。侧栏宽度、折叠状态、排序和隐藏已完成、是否显示大纲这类显示偏好只记在本机
- 整体的UI风格设计需要中国用户的使用习惯
- 首页以卡片列出全部工作区（项目数（顶层项目，子项目不另算）、待办数（包括子项目里的）、完成进度、最近更新时间）；工作区、项目都能新建、重命名、删除、在资源管理器中打开，删除前要确认，删除的内容先进软件的回收站（见下一条）
- 回收站：删除的工作区、项目、待办（包括批量删除的）先放进软件的回收站（数据目录下的 `.recycle`，每项一个目录，`entry.json` 记着原来在哪里，待办连同标题、完成状态、置顶、创建 / 完成时间，和它的图片（附件目录，见「待办内容 → 图片」）放在同一项里），删除后的提示里带「撤销」（几秒内有效），撤销的是正打开着的待办时重新打开它，撤销删除工作区时重新选中它。首页头部和侧栏底部的「回收站」列出回收站里的东西（最近删除的在前，可以按名称、原来的位置查找），可以恢复到原来的位置或彻底删除，也可以清空。恢复时原来的工作区、项目已经不在就重新建；项目、工作区原来的名字被占用了就改名（加「（恢复）」），待办的文件名被占用了换一个；恢复的待办在手动排序时排在最前面。彻底删除、清空和放满 30 天的（启动时检查）移到 Windows 回收站：连同说明一起移，在 Windows 回收站里显示成标题（或项目、工作区名）加 id，从那里还原后回到软件的回收站，还能接着恢复到原来的位置。回收站在数据目录里，数据目录用网盘同步时一起同步；不会被当成工作区，也不会被搜到。回收站开着时，回收站在外部变了（从 Windows 回收站还原回来的、网盘同步来的）列表跟着刷新
- 支持浅色 / 深色 / 跟随系统三种主题（默认跟随系统），窗口标题栏跟着切换；点首页、侧栏顶部的主题按钮或在设置的「外观」里切换，立即生效。主题存在设置文件里，随设置一起备份和恢复
- 字号可调：左侧的工作区、项目与待办列表（12–20px，默认 14px）和右侧的待办编辑区（12–32px，默认 15px）在设置的「外观」里分别修改，调整后立即生效、可恢复默认；编辑区还可以按住 Ctrl 滚动鼠标滚轮快速调整，状态栏显示当前字号、点击恢复默认。字号存在设置文件里，随设置一起备份和恢复
- 右侧待办编辑区的背景色可选护眼米色（默认）、白色（和界面其他部分一致）或自定义，在设置的「外观」里修改，立即生效；自定义时输入 RGB 数值（各 0–255，默认豆沙绿 199, 237, 204），颜色太深时提示文字可能看不清；自定义的颜色在改选其他背景色后仍保留。只在浅色模式下区分，深色模式下编辑区始终是深色背景。背景色存在设置文件里，随设置一起备份和恢复
- 同一时间只运行一个实例：再次启动时把已运行的主窗口调到前台（包括藏在托盘里时）；记住窗口大小和位置
- 开屏：打开软件时显示首页（默认），或回到上次的位置（左侧选中了哪些工作区、右侧正在编辑哪个待办，光标也回到上次编辑的地方），在设置的「常规」里修改，下次启动时生效。上次停在首页时仍显示首页；上次右侧显示的工作区已不在时显示还在的选中工作区中的第一个，都不在了就显示首页；项目、待办不在了退回上一级。开屏方式存在设置文件里，随设置一起备份和恢复；上次的位置记在 `.state.json`

## 工作区界面

- 进入工作区或工作区-项目后，左侧可以显示可折叠的工作区内容、项目内容，两个层级都可以折叠，todo item显示title，如果没有title，显示前几个字符（具体几个根据左侧空间确定）
- 子项目：
  - 侧栏里子项目列在父项目下面、父项目自己的待办前面（同资源管理器里文件夹排在文件前面），缩进一级，按名字排；父项目、子项目各自可以折叠
  - 新建：右键顶层项目、项目行上的「…」、项目概览和侧栏顶部的「新建」里的「新建子项目」（右侧显示着子项目或其中的待办时，「新建」里的是在它的父项目里新建）；子项目上没有这一项
  - 统计：父项目行上的未完成数、项目概览的完成进度和数目、工作区概览的项目卡片包括子项目里的待办；工作区概览的「项目」数和项目卡片只算顶层项目，卡片上写明有几个子项目
  - 父项目的项目概览：上面是子项目的卡片（点进去，最后一张是新建子项目），下面是父项目自己的待办；快速添加的待办加在父项目自己里
  - 改名：子项目改名后仍在原来的父项目里；父项目改名后子项目跟着，标签、编辑位置、后退 / 前进等记住的东西都跟着走
  - 删除：删除父项目时连同子项目一起进回收站（确认里写明有几个子项目和一共几条待办）；回收站里的子项目恢复到原来的父项目里，父项目不在了就重新建。删除工作区的确认里（首页、侧栏都是）项目数同首页的卡片，只算顶层项目，待办数包括子项目里的
  - 显示项目路径的地方（标签的悬停、编辑区上方、搜索结果、批量操作、回收站、「移动到」、快速记录存到哪里、拖动和操作后的提示）写成「父项目 / 子项目」；编辑区上方、项目概览上方的父项目也能点
  - 移动：项目可以放进别的顶层项目成为子项目，子项目可以移出来变成顶层项目，都可以跨工作区（见「拖动移动项目」和右键「移动到」）
  - 键盘：左侧列表里在子项目上按 ← 先折叠，已经折叠着时回到父项目；待办上按 ← 回到它所在的（子）项目
  - 搜索按子项目自己的名字匹配（不看父项目的名字）：侧栏里子项目命中时连同它的父项目一起列出，首页的结果里写明在哪个父项目里
  - 快速记录可以存到子项目里
- 在左侧的todo item上的合适位置加上完成标识、创建时间与最新修改时间
- 侧栏宽度可拖动（双击拖动条恢复默认），折叠状态（每个工作区各自保存）和宽度下次打开时保持；侧栏顶部可返回首页
- 侧栏顶部的「全部折叠 / 全部展开」一次折叠 / 展开侧栏里各工作区的全部项目和子项目：看得见的项目有展开着的时是「全部折叠」，都折叠着时是「全部展开」。看不见的不算：折叠着的工作区里的项目、折叠着的父项目里的子项目，「隐藏全部完成的项目」藏起来的（见下面）；算进去的话按钮显示「全部折叠」，点了界面却没有变化。「全部折叠」只折叠项目，工作区那一级不动；「全部展开」时折叠着的工作区也一起展开，不然展开了也看不见
- 侧栏顶部「选中工作区」：勾选要显示的工作区，可多选（全选、「仅显示」某一个），选中多个时左侧同时显示这几个工作区的树，各自可折叠；至少要选中一个。右侧显示点中的那个工作区的概览 / 项目 / 待办，「新建」和 Ctrl+N 作用于它；右侧正在显示的工作区被取消选中时改显示第一个。选中的工作区会记住：下次从首页进入时恢复上次选中的那几个，再加上这次进入的（右侧显示进入的那个）；已被删除的悄悄去掉，在首页改名的跟着改
- 侧栏提供搜索（Ctrl+Shift+F，在选中的工作区里匹配项目名、待办标题与正文全文，关键字高亮，命中在正文里的待办在标题下面显示关键字附近的一段（代替创建、修改时间）；在搜索框里按 Esc 清空搜索，焦点回到左侧列表，可接着用方向键移动）、隐藏已完成（已完成的待办、全部完成的项目，见下一条）、按创建时间 / 修改时间 / 标题排序或手动排序。排序和隐藏已完成每个工作区各自记住（项目概览的排序跟着所在的工作区），选中多个工作区时侧栏顶部的这两个按钮作用于右侧正在显示的那个；还没单独设置过的工作区沿用以前不分工作区时的设置
- 隐藏已完成：侧栏顶部的「隐藏已完成」按钮点开是两个各自开关的选项，开着的前面打勾，开着任何一个时按钮显示成「已隐藏」的样子，悬停说明隐藏了哪些：
  - 隐藏已完成的待办：侧栏里只列未完成的待办；项目里的待办都藏起来了时显示「已隐藏 N 条已完成的待办」
  - 隐藏全部完成的项目：项目里有待办、而且全都完成了的，侧栏里连同其中的待办都不显示。没有待办的项目（刚建的）不算全部完成，照常显示；里面有一条变成未完成（新加的、改回未完成的、移进来的）就又显示出来。默认不隐藏（以前的版本里设过「隐藏已完成」的工作区，这一项也是不隐藏）
  - 有子项目的：父项目自己和子项目里的待办合起来看，都完成了才算全部完成，连同子项目一起藏起来；父项目还没全部完成时，其中全部完成的子项目单独藏起来。「已隐藏 N 个」数的是藏起来的父项目和单独藏起来的子项目
  - 隐藏了项目的工作区，在它的项目下面显示「已隐藏 N 个全部完成的项目，显示」，点「显示」关掉这个工作区的这一项
  - 右侧正在显示的项目（项目概览，或者打开着其中的待办，包括经标签、后退 / 前进、搜索结果打开的）即使全部完成也照常显示：免得正看着的东西从左边消失、用键盘上下移动时找不到当前位置。显示的是子项目（或其中的待办）时，它的父项目也照常显示
  - 切到别处（别的项目、工作区概览、别的工作区，用鼠标、键盘、标签都算）后，它再显示 1 秒才藏起来。1 秒比 Windows 的双击间隔（默认 0.5 秒，最长约 0.9 秒）长：在它下面的项目里双击待办（固定标签）、双击项目（折叠）时，第一下点击切走后它不会马上消失、让下面的行整体上移到鼠标底下，第二下还落在同一行上。这 1 秒里切回它就接着显示；又换了右侧显示的内容（包括又点了一下正显示着的、又切走了另一个全部完成的项目）时从这一下重新算 1 秒，切走过的到时一起藏起来，免得在接着的双击中间藏起来。只有切走时已经全部完成、会被藏起来的才再显示 1 秒；别的变化照常立即生效：开关这一项、开始 / 清空搜索、其中的待办改成完成 / 未完成
  - 侧栏搜索时不隐藏全部完成的项目，名字或其中的待办命中的照常列出（其中的已完成待办是否列出仍按「隐藏已完成的待办」）
  - 侧栏顶部的「全部折叠 / 全部展开」不算藏起来的项目：没藏起来的（包括右侧正在显示的、切走后还在显示的）都折叠着时就是「全部展开」，藏起来的展开着也不算——它们看不见、折叠不了，算进去的话折叠完看得见的项目后按钮还是「全部折叠」，点了界面没有变化。点了连藏起来的一起折叠 / 展开：关掉这一项、其中的待办改回未完成后再显示出来时，它们和别的项目一样折叠着 / 展开着
  - 只影响侧栏：工作区概览的项目卡片、右键「移动到」和批量操作的项目列表、快速记录存到哪个项目、首页搜索照常列出全部项目；工作区行上的未完成数、侧栏底部的统计照常算全部。藏起来的项目不能作为拖动的目标
  - 两项可以一起开：全部完成的项目整个不显示，别的项目里只显示未完成的待办
- 手动排序：在左侧列表或项目概览里把待办拖到同一项目里的另一条待办上，放在它前面（指针在那一行的上半截）或后面，拖动时画出插入线、说明放在哪条前后。拖完这个工作区改成手动排序（没在手动排序时提示一下），可以在排序按钮里换回别的排序。顺序记在 `.todos.json`，不算修改，修改时间不变；没排过位置的（新建的、移过来的）排在最前面。已完成的和未完成的、置顶的和没置顶的各排各的，不能拖到另一类旁边；搜索时不能调整顺序
- 置顶：置顶的待办在左侧列表和项目概览里排在最前面（不论按什么排序；已完成的仍沉到未完成的后面，置顶的已完成排在已完成里的最前面），标题前有图钉，编辑区标「已置顶」。置顶记在 `.todos.json`，不算修改，修改时间不变；移到别的项目后仍是置顶的
- 从首页进入工作区（点卡片、右键「进入工作区」、搜索结果里的工作区）时，直接打开上次在这个工作区打开的待办；这个工作区还没打开过待办时显示工作区概览，那条待办或所在的项目已不在时退回上一级。各工作区上次打开的待办记在 `.state.json`，工作区 / 项目改名、待办移动后跟着走（移到别的工作区的不再算原工作区的）
- 没有选中待办时，右侧显示概览：工作区概览统计项目数、待办总数、未完成、已完成、完成率；项目概览显示完成进度和待办列表，可以输入标题按 Enter 快速添加待办
- 右侧标签页：可以同时打开多条待办，右侧上方一排标签，每个是一条打开着的待办，点标签来回切换（同 VS Code）：
  - 打开：在左侧列表、项目概览、搜索结果里单击（或用键盘移到、后退 / 前进到）一条待办，打开在「预览」标签里（标题是斜体），再打开别的待办时预览标签被替换（在原处），浏览列表时标签不会越开越多。修改了它的标题或正文、在左侧列表里双击它、双击标签或右键标签选「保持打开」后变成固定的标签，一直留着直到关掉。新建的待办（包括快速记录里按 Ctrl+Enter 打开的、外部修改冲突时另存的新待办）直接开在固定的标签里。已经有标签的待办再打开时切到那个标签、不挪位置；新开的标签放在正显示着的标签右边
  - 切换：点标签，或 Ctrl+Tab / Ctrl+Shift+Tab 切到下一个 / 上一个标签（到头了从另一头接着；正显示着概览时 Ctrl+Tab 到第一个、Ctrl+Shift+Tab 到最后一个）。切过去时光标、选区和滚动回到上次在这条待办里的地方（见「回到上次编辑位置」），焦点直接放进正文，接着打字就在原来的光标处；左侧列表展开它所在的分支、选中它。离开的那条和切换待办一样先保存
  - 关闭：标签上的 ×、鼠标中键、Ctrl+W；右键标签可以关闭、关闭其他标签、关闭右侧标签、关闭全部标签。关掉前和切换待办一样先保存，不用确认。关掉的是正显示着的标签时切到它右边的标签（右边没有时左边的），都关掉了显示它所在的项目
  - 调整顺序：按住标签左右拖动，放在指针下那个标签的前面（指针在它的左半边）或后面，拖动时画一条竖线标出放下的位置、拖着的标签变淡；按下后移动几个像素才开始拖，没怎么动仍是单击；靠近标签栏两头时自动滚动，按 Esc 或窗口失去焦点时取消。拖动不切换标签；藏起来的标签（没选中的工作区里的）和别的标签的相对顺序不变
  - 右侧显示概览、批量操作时标签仍在，没有哪个高亮，点标签回到那条待办
  - 只显示侧栏里选中显示的工作区里的待办的标签；取消选中的工作区的标签藏起来，再选中时回到原来的位置
  - 未保存：正显示着的待办有没存好的修改（未保存、正在保存、保存失败，同状态栏）时，标签上 × 的位置显示一个圆点，鼠标移到圆点上变回 ×，悬停标签时说明关掉、切走时会先保存。切走总会先保存，别的标签不会有圆点
  - 悬停标签显示「工作区 / 项目 / 标题」，预览标签还说明会被替换；没有标题时显示正文开头，已完成的标题带删除线，置顶的带图钉
  - 标签（顺序（包括拖动调整过的）、哪个是预览标签）记在 `.state.json`，下次打开软件还在；工作区 / 项目改名、待办移动后跟着走，待办（或所在的项目、工作区）删除后关掉，在外部被删了的刷新后关掉
- 右键工作区 / 项目 / 待办弹出操作菜单；待办的菜单提供用默认程序打开、标记完成 / 未完成、置顶 / 取消置顶、移动到其他项目、在资源管理器中显示、删除。「移动到」和拖动能去的地方一致：只显示一个工作区时列出同一工作区的其他项目；同时显示了几个工作区时，其他选中工作区的项目也列出来，按工作区分组（所在的工作区排第一，标上「当前」），没有可移去的项目的工作区不列；项目多时子菜单可以滚动
- 拖动移动待办：在左侧列表或项目概览里按住待办，拖到左侧的另一个项目上松开即移过去，可以是同时显示的其他工作区里的项目（项目下面的待办、「暂无待办」处都算这个项目）。按下后移动几个像素才开始拖，没怎么动仍是单击；拖动时跟着指针显示拖的是什么、会移到哪里（或该往哪里拖），能放下的项目连同其中的待办整块高亮，原处不高亮；在折叠起来的工作区上停一会儿自动展开，靠近列表上下边缘时自动滚动；按 Esc 取消。移动前先保存正在编辑的内容，编辑位置、编辑模式、撤销记录和后退 / 前进的记录跟着走；待办的图片（附件目录）跟着移过去（见「待办内容 → 图片」）
- 批量操作：在左侧列表里 Ctrl+单击加选 / 取消一条待办（还没多选时从正打开着的那条开始），Shift+单击选中从上次点的那条到这一条之间的一段（按列表里显示的顺序，折叠起来的不算），可以跨项目、跨同时显示的工作区。选了两条以上时右侧显示批量操作：标记为已完成 / 未完成、置顶 / 取消置顶、移动到（列出侧栏里显示的各工作区的项目）、删除（先确认），以及选中的待办列表；在选中的待办上右键是同样的菜单；按住选中的任意一条拖到左侧的项目上，选中的一起移过去（已经在那里的不动）。Esc 取消选择、Delete 删除选中的、「标记完成 / 未完成」的快捷键作用于选中的这些；普通单击、用键盘移动、返回首页等右侧改显示别的内容时取消多选。部分没有成功的提示失败的条数和原因，成功的照常算
- 拖动移动项目：在左侧列表、工作区概览或父项目概览里按住项目（或子项目），项目连同其中的待办（和子项目）移过去，名字不变：
  - 拖到左侧的另一个顶层项目上（它的行、子项目、待办哪里都算，在子项目上算放进它的父项目）松开：放进去成为它的子项目，可以是同时显示的其他工作区里的项目
  - 拖到工作区那一行（或工作区里项目以外的地方，如「还没有项目」）上松开：移到这个工作区的顶层；子项目这样移出来，变成普通项目
  - 只有一层子项目：有子项目的项目不能放进别的项目（标红，说明原因），可以整个移到别的工作区；那里已有同名项目（不分大小写）时标红、不能放下；放回原处、放进它自己不算能放的地方
  - 拖动的方式、说明、自动滚动、在折叠起来的工作区上停一会儿自动展开、Esc 取消、先保存、状态跟着走同拖动待办，项目（和子项目）的折叠状态也跟过去，目标工作区和放进的项目自动展开
- 右键项目「移动到」：和拖动能去的地方一致——同时显示的各工作区（只显示一个时不分组，所在的工作区排第一，标上「当前」）的顶层（子项目移出来时写明从哪个项目移出）和其中的顶层项目；已经在那里的、放不进去的不列，有同名项目的列出来但不能点

## 待办内容

- 点击某个todo item后，右侧显示具体的todo内容，支持右键todo item通过系统默认的markdown软件打开。todo item实际上包括：title、content，title单独存储，content存储到markdown文件中，并遵循{工作区}、{项目}的目录结构。
- 回到上次编辑位置：切换回某条待办（包括点标签切换、开屏回到上次的位置）时，光标和滚动回到上次在这条待办里编辑的地方（光标在编辑区里的高度也和离开时一样），离开时选中了一段文字的，选区也恢复。正文在外部被改过时，按光标（选区两端）前后的原文找回位置，选区另一端找不到时只放光标；被大幅修改、找不到时回到开头。打开着的待办被外部修改、重新加载时同样处理。编辑位置记在 `.state.json`，工作区 / 项目改名、待办移动后跟着走
- 撤销记录：切到别的待办（包括返回首页）再切回来，仍能用 Ctrl+Z / Ctrl+Y 撤销、重做之前的修改。只在这次运行期间保留，每条待办各留一份（最多 50 条，最久没打开的先忘掉）；正文在外部被改过时作废，从头记起（打开着的待办被外部修改、重新加载时同样清空；外部只是重写了一遍、内容没变的不算，撤销记录还在）。工作区 / 项目改名、待办移动后跟着走
- 正文用 Markdown 编辑，有两种模式，按 Ctrl+/ 或点状态栏切换。所选模式每条待办分别记住（记在 `.state.json`，工作区 / 项目改名、待办移动后跟着走）；没切换过的待办用实时渲染，以前不分待办时选了源码模式的沿用源码模式：
  - 实时渲染（默认，类似 Typora）：标题、加粗、斜体、删除线、下划线（`<u>` 标签）、行内代码、链接、图片、表格（见下面的「图片」「表格」）、引用、列表、任务框、分隔线、代码块显示成渲染后的样子，光标（选区）所在的元素显示原文以便修改；点任务框直接勾选 / 取消
  - 源码模式：显示全部 Markdown 标记，只做语法高亮
  - 两种模式都只改变显示，正文按原样保存，不会改动文件里原有的写法（不能像富文本编辑器那样保存时重新生成 Markdown）
  - 按住 Ctrl 单击链接用系统浏览器打开，只允许 http / https / mailto；回车自动续写列表和任务；在列表里按 Tab / Shift+Tab 缩进列表项（见「编辑快捷键」），不在列表里时 Tab 插入两个空格
  - 代码块（同 Typora）：输入 ```语言 后回车自动补上结尾的 ```；在代码块里按 Ctrl+Enter，或在文末代码块的最后一行按 ↓，跳到代码块下面新的一行，缺结尾的 ``` 时顺便补上
- 图片（同 Typora）：正文里可以粘贴、拖进图片，实时渲染模式下显示成图片
  - 存放：粘贴、拖进来的图片复制一份，存在待办所在的项目文件夹里的附件目录，每条待办一个子目录：`{项目文件夹}\.assets\{待办 id}\{文件名}`（`.` 开头的文件夹不算子项目）。正文里写相对于 .md 文件的地址 `![说明](.assets/{待办 id}/{文件名})`（说明是去掉扩展名的文件名；地址里有空格、括号时写成 `<…>`，同 Markdown 的规则），用默认程序（Typora、VS Code）打开 .md 时也能显示。粘贴的截图等命名为 `图片-年月日-时分秒.png`（扩展名按图片的格式），拖进来的文件保留原名（Windows 文件名里不能用的字符和 `#` 换成 `_`）；同名时在后面加 `-2`、`-3`…；拖进来的和附件目录里已有的同名文件内容一样时直接用已有的，不再复制一份
  - 粘贴：在正文里 Ctrl+V，剪贴板里有图片（截图、从浏览器复制的图片）、没有文字时，存成图片文件，在光标处插入（选中了文字时替换选中的）；剪贴板里同时有文字时（如从 Word、Excel 复制的内容，往往还带着一张选中部分的图片）照常粘贴文字；剪贴板里只有不是图片的文件时提示「只能粘贴图片」
  - 拖进来：从资源管理器把图片文件拖到正文里，复制一份到附件目录（原文件不动），插在放下的位置；拖动时在正文里画一条竖线标出会插在哪里。能插入的图片：png、jpg / jpeg、gif、webp、bmp、svg、ico、avif；拖进来的有不是图片的时提示，其中的图片照常插入；拖到正文以外的地方什么都不做。侧栏里拖动待办、项目不受影响
  - 一次粘贴、拖进几张时每张一行。两种模式都能用；只读的正文（编码认不出）不能插入，提示原因。插入算修改，和打字一样要保存、可以撤销；撤销了、从正文里删掉了的图片文件留着（还可能撤销回来），删除待办时整个附件目录跟着走。图片超过 20 MB 时照常插入，提示它很大（占用数据目录的空间，网盘同步也慢）
  - 显示：实时渲染模式下光标不在那一行时显示成图片（宽度不超过编辑区，比编辑区宽的按比例缩小，窄的按原来的大小），鼠标悬停显示地址；单击图片光标放进这一行、显示原文以便修改，同其他元素。显示不了时显示一个占位框，写明原因：找不到图片、不是图片文件、图片加载失败（格式不支持或文件损坏）、网络图片加载失败、不支持的地址。源码模式只显示原文
  - 支持的地址：相对于 .md 文件（即项目文件夹）的本地路径（包括 `.assets` 以外的，如 `../图片/a.png`；`%20` 这类转义照样认），本地绝对路径（`C:\…`、`C:/…`、`file:///C:/…`、`\\服务器\共享\…`），http / https 图片，`data:image/…`；`![说明][引用]` 这样引用别处地址的也认
  - 本地图片经 Tauri 的 asset 协议读：数据目录（用 `TODOLIST_DATA_DIR` 指定了别的数据目录时是它）整个放开；数据目录以外的图片，正文里引用到时只放开那一个文件，而且只放开上面那些扩展名的图片，别的文件经它读不到。网络图片由 WebView 直接下载（对方网站能看到有人打开了它）
  - 跟着待办走：
    - 移动待办到别的项目（右键「移动到」、拖动、批量移动，包括移到别的工作区）：附件目录一起移过去；那里重名、换了 id 时附件目录改成新 id，正文里地址以 `.assets/{旧 id}/`（或 `./.assets/{旧 id}/`）开头的改成新 id，别处不动。这样改正文是软件自己的写入：不算修改，.md 的修改时间留着原来的，撤销记录接着用。图片被别的程序占用、移不动时这条待办不移，提示原因
    - 删除待办：附件目录连同 .md 放进回收站的同一项里（`{这一项}\{待办 id}.md` 和 `{这一项}\.assets\{待办 id}\`，在 Windows 回收站里用 Typora 打开那个 .md 也看得到图片）；撤销、恢复时一起回来，id 变了时同上改链接；彻底删除、清空、放满 30 天的连同图片一起进 Windows 回收站。图片被占用、移不动时不删除
    - 外部修改冲突时「另存为新待办」（包括离开时存不上自动另存的）：新的那条复制一份原来那条的附件目录，正文里的链接改成新的 id，免得以后删了原来那条图片就没了；复制失败时照常另存，链接仍指向原来那条的图片
    - 项目、工作区改名、移动、删除时，附件目录在项目文件夹里，跟着一起
    - 附件目录不算子项目，里面的 .md 不算待办，全文搜索不查；新建、移动、恢复待办时不用附件目录已经在了（如外部留下的）的 id
  - 监听数据目录时不看附件目录（见「监听数据目录」）：外部在里面增删、替换图片不刷新；被替换了的图片下次显示时（光标离开那一行后、重新打开这条待办时）换成新的
- 表格（GFM 表格，同 Typora）：
  - 实时渲染模式下，光标（选区）不在表格里时整个表格显示成渲染后的表格：表头加粗、有底色；各列按分隔行的 `:---`、`:---:`、`---:` 左对齐、居中、右对齐；单元格里的加粗、斜体、删除线、行内代码、链接、图片、`<br>` 换行也渲染，`\|` 显示成 `|`。内容行的格子比表头少时空着，多出来的不显示（同 GFM）
  - 光标（选区）在表格里时整个表格显示原文。单击渲染后的表格，光标放进点的那一格原文的末尾（空的格子放在两个 `|` 中间），表格显示原文以便修改；按住 Ctrl 单击单元格里的链接用浏览器打开。编辑器没有焦点时全部渲染；按着鼠标拖选时先不切换，松开后再切换（同其他元素）
  - 表格很宽（列多、格子里有很长的网址）时在编辑区里横向滚动，不撑破编辑区；格子里的文字照常换行
  - 只渲染不在列表、引用里的表格，列表、引用里的显示原文。源码模式只显示原文；只改变显示，正文按原样保存
  - Ctrl+T 插入一个空表格（见「编辑快捷键」）
- 正文里查找 / 替换：打开着待办时按 Ctrl+F 在正文里查找（焦点在左侧列表、标题上时也行），查找框在正文上方，不随正文滚动；输入时直接跳到光标后面最近的结果（到末尾后从头找），显示第几个 / 共几个，Enter / Shift+Enter（或 F3 / Shift+F3）找下一个 / 上一个，可选区分大小写、全字匹配、正则表达式；Esc 关闭查找框、回到正文。Ctrl+H 同时展开替换（还没填查找内容时先填查找内容），可以逐个替换或全部替换，只读的正文不能替换。打开查找框时选中了一行以内的文字就查它，否则接着用最近一次查过的内容（在别的待办里查的也算）。替换和手动修改一样可以撤销
- 长文档的大纲：正文里有 2 个以上标题时，在正文右侧列出标题（# 标题和下面画 === / --- 的标题，引用、列表里的也算，代码块里的不算），去掉加粗、链接地址这些标记，按级别缩进；点标题跳过去（光标放在那一行末尾，标题滚到顶部）。正在看的那一节高亮：光标在可见区域里时按光标，否则按可见区域顶部；打字停下片刻后大纲跟着更新。点状态栏的「大纲」或按 Ctrl+Shift+1（同 Typora）显示 / 隐藏，所有待办共用、只记在本机，默认显示；编辑区太窄时不显示
- 保存方式在设置的「保存」里修改，立即生效，存在设置文件里，随设置一起备份和恢复：
  - auto save（默认关闭）：开启后，编辑器失去焦点、窗口失去焦点（包括隐藏到托盘）时立即保存，另外定时保存——标题或正文改动后按设置的间隔自动保存（默认 3 分钟，可设 1 秒到 60 分钟），从第一处未保存的修改开始计时，继续输入不会推迟保存
  - 不论 auto save 开没开，Ctrl+S 立即保存，切换待办（包括关标签、返回首页、新建待办等离开当前待办的操作）和从托盘退出前总是先保存（这时存不上的自动另存为新待办，不会悄悄丢掉，见「感知外部修改」），重命名、移动、删除、用默认程序打开之前也总是先保存：存不上（文件在外部被改过、弹出了冲突对话框，或保存失败）时不做这个操作，冲突对话框留着让用户先处理，并提示为什么没做（重命名的对话框留着、在输入框下面说明，处理完再点确定）；拖动移动、右键「移动到」同样
  - 关闭 auto save 时，失去焦点、隐藏到托盘都不保存，除了上面这些时候，只有一个兜底：标题或正文有未保存的修改，满 1 小时自动保存一次（同样从第一处未保存的修改开始计时，继续输入不会推迟），窗口藏在托盘里时也照常触发。免得程序在托盘里挂好几天、改了的内容一直只在内存里，系统重启或 WebView2 崩溃就丢了
  - 输入法组合中（拼音还没上屏）的内容不算修改，不会存盘，上屏后才算
- 底部状态栏显示保存状态、字数、行数和正文文件路径，点击路径复制
- 感知外部修改：窗口重新获得焦点时、以及运行期间数据目录里的文件在外部变化时（网盘同步下来的、别的程序保存的、在资源管理器里增删改名的；窗口一直在前台、没有切换焦点也算），自动从磁盘刷新：侧栏、首页（工作区卡片和统计、搜索结果）、工作区概览、项目概览跟着变，打开着的待办（或它所在的项目、工作区）在外部被删了时退回上一级（见下面的「监听数据目录」）。正文文件在外部被改过时，这里没有未保存的修改就重新加载（光标、选区按「回到上次编辑位置」找回，撤销记录清空）；有的话立即弹窗（不等到保存、离开时才发现，正在编辑的内容不动），让用户选择「放弃我的修改，重新加载」「用我的内容覆盖」或「另存为新待办」。外部只是把同样的内容重写了一遍（修改时间变了、内容和打开时一样，如网盘同步）或者改成了和这里一样的，不算冲突，也不重新加载（光标、撤销记录都不动）。还没刷新出来就保存的（监听不可用，或者刚改完、还没等到刷新），保存时发现，同样弹窗。「另存为新待办」两份都保留：这里的正文连同标题存成同一项目里的一条新待办（标题后面加上「（我的版本）」，没有标题时取正文第一行），正文和待办一次建好，不会出现先建空文件再存正文的中间状态；这一条重新加载外部的版本；然后打开新的那条，编辑位置、撤销记录和编辑模式跟过去，接着原来的地方编辑，并提示新待办的标题
  - 监听数据目录：运行期间监听整个数据目录（含各级子文件夹；用 `TODOLIST_DATA_DIR` 指定了别的数据目录时监听它）
    - 一阵变化合起来算一次：最后一处变化之后静下来 0.3 秒再刷新；一直在变的（网盘在同步一大批文件、恢复数据）最多攒 2 秒刷新一次。一次变了很多（200 处以上；系统的变化通知来不及时会丢掉一些、不报错）时当成什么都可能变了，全部刷新一次。几千个文件一起变也只刷新几次，不卡
    - 只刷新有变化的：侧栏里选中显示的工作区有变化才重新加载，内容没变的工作区、项目、待办不重新渲染；首页在哪个工作区有变化时都重新统计；打开着的待办只在它的正文文件或它所在的项目、工作区文件夹变了时核对磁盘（同「窗口重新获得焦点」）
    - 不算的：数据目录里 `.` 开头的（界面状态 `.state.json`、设置文件、`.trash` 等；软件的回收站 `.recycle` 只用来刷新开着的回收站列表）和直接放在数据目录、工作区文件夹里的文件（如设置备份的 zip）；项目文件夹里 `.` 开头的（保存时的临时文件 `.名字.tmp`、损坏的元数据留档 `.todos.json.broken-*`、图片的附件目录 `.assets` 等；元数据 `.todos.json` 算）、不是 .md 的文件，子项目里的文件夹；文件夹自己的修改时间变了不算（里面增删改名的东西自己有变化）
    - 软件自己的写入（保存正文和标题，改完成状态、置顶、顺序，新建、改名、移动、删除、恢复，扫描时补登记元数据等）不引起刷新：写完记下这些文件、文件夹现在的样子（文件的修改时间和大小，在不在），监听到的变化和记下的一样就是自己写的，忽略（只认 10 秒内写的）；之后外部又改了的照常刷新。打字、保存时不会因此闪一下或重新加载
    - 主窗口藏在托盘里时不刷新，记下有变化，显示出来时再刷新一次；快速记录小窗每次弹出时重新列出项目
    - 监听建不起来（如数据目录在不支持变化通知的网络盘上）或中途出错时，悄悄退回只在窗口获得焦点（和 F5）时刷新，不弹窗；建不起来的原因写在标准错误输出里
    - 没有变化时监听线程一直等着系统的通知，不占 CPU
  - 离开时存不上：离开这条待办（切换待办、关标签、返回首页等，正显示着冲突对话框时被切走也算）或从托盘退出时存盘才发现文件在外部被改过，这时没法再让用户选，自动「另存为新待办」，两份都保留：这里的正文连同标题（同上加「（我的版本）」）存成同一项目里的一条新待办，原来那条是外部的版本。不打开新的那条：提示它的标题，左侧列表里列出它，打开它时编辑位置、撤销记录和编辑模式跟过去
  - 待办或所在的项目在外部被删了等原因存不上时，同样另存为新待办，提示里说明没能保存的原因；原来的项目也不在了时存到快速记录存到的项目（不在时新建；不把在外部删掉的项目建回来），提示里写明存到了哪里。另存也失败时明确提示，正文复制到剪贴板
  - 从托盘退出时等这些做完再退出（最多等 10 秒）；另存也失败、或 10 秒内没存完时不退出，调出主窗口，问是否仍要退出（修改还在编辑区里）
- 用户直接放进项目文件夹的 .md 文件自动识别为新待办（文件名作为标题）；存标题等信息的 `.todos.json` 损坏时先备份再重建，正文不受影响
- 正文统一以 UTF-8 保存；用户放进来的 GBK（ANSI）或带 BOM 的 UTF-16 文件要能正常显示，在软件里修改后转存为 UTF-8；认不出编码的文件只读显示、不能在软件里保存，避免把原文件覆盖成乱码

## 窗口与系统集成

- 点击窗口右上角的关闭按钮（❌）时最小化到系统托盘，而不是退出程序；左键单击托盘图标恢复窗口，右键托盘图标的菜单提供「显示主窗口」「快速记录」「退出」，只有从托盘菜单「退出」才真正结束程序（退出前要保存正在编辑的内容；存不上的另存为新待办，另存也失败时不退出、问用户，见「感知外部修改」）
- 快速记录：按全局快捷键（默认 Ctrl+Alt+N）或托盘菜单的「快速记录」，不用打开主窗口，在鼠标所在的屏幕上弹出一个置顶的小窗（无边框，标题处可以拖动，不出现在任务栏和 Alt+Tab 里）；写一段文字，第一行当标题、其余当正文（第一行太长时整段当正文），Enter 保存，Shift+Enter 换行，Ctrl+Enter 保存后在主窗口里打开它；输入法组合中的 Enter 不算。默认存到「收件箱」工作区的「快速记录」项目，不在时保存时新建；小窗右上角和设置的「常规」里可以改存到哪个项目，改了就记住，工作区 / 项目改名、移动后跟着改。保存后小窗藏起来、主窗口跟着刷新；Esc、点到别处、再按一次快捷键也藏起来，没存的草稿留着（本机记住，下次弹出还在）。小窗的主题跟着设置
- 窗口在标题栏、任务栏、Alt+Tab 等处显示的图标都要与应用图标一致，不能出现系统默认图标
- 开机自启：在设置的「常规」里打开 / 关闭（默认关闭），写在注册表的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（启动项名是产品名，程序路径带引号，后面带 `--autostart`）。开没开以注册表为准，是这台电脑上的设置，不进设置文件、不随备份恢复；在任务管理器的「启动应用」里禁用了的算关闭，在软件里重新打开时改回启用；卸载（不是升级）时删掉启动项。开机自启时默认只在托盘里、不显示主窗口，可以改成显示主窗口，这个选项存在设置文件里，随设置一起备份和恢复

## 搜索

- 首页（能看到全部工作区时）提供搜索（Ctrl+Shift+F，首页上 Ctrl+F 也行），跨全部工作区查找工作区名、项目名、待办标题与正文全文，命中在正文里的显示关键字附近的一段；点击搜索结果直接进入对应的工作区 / 项目 / 待办
- 全文搜索（侧栏和首页）不区分大小写，GBK 等编码的正文也能查；在 Rust 端查，正文缓存在内存里（文件没变就不重新读，不写进任何文件），输入停下片刻再查，查完之前先列出标题和正文开头匹配的；数据刷新、保存后重新查

## 快捷键

- 提供可配置的全局快捷键，默认 Ctrl+Alt+T：主窗口在前台时最小化到系统托盘，否则显示主窗口并调到前台；快速记录的全局快捷键默认 Ctrl+Alt+N（加这个功能之前已经把别的快捷键设成了 Ctrl+Alt+N 的，快速记录让给它、设为不使用）。都可以在设置里修改、恢复默认或不使用，快捷键被其他程序占用时要提示
- 程序在前台且选中了某个待办时，默认用 Ctrl+Alt+D 标记完成 / 未完成、Ctrl+Alt+O 用默认程序打开；这两个快捷键也能在设置里修改、恢复默认或不使用，各快捷键之间不能重复
- 鼠标侧键后退 / 前进：在这次运行期间看过的地方之间来回，和浏览器一样——首页、工作区概览、项目概览、待办各算一处，在中间某处又去了新的地方时前进的记录清掉；用键盘在左侧列表里连着移动、停不到 1 秒就移走的不算看过。回到的工作区没选中时自动选中，并展开它所在的分支；工作区 / 项目改名、待办移动后跟着走，删除的不再回去；最多记 100 处。对话框里不响应
- 应用内固定快捷键：Ctrl+N 新建（首页新建工作区，工作区内在当前项目新建待办）、Ctrl+S 立即保存、Ctrl+Shift+F 搜索（工作区里聚焦侧栏搜索框，首页聚焦首页搜索框）、Ctrl+F / Ctrl+H 在正文里查找 / 替换（没有打开待办时 Ctrl+F 聚焦侧栏搜索框，首页上聚焦首页搜索框）、F5 / Ctrl+R 刷新（从磁盘重新读取，不让 WebView 整页重新加载；带别的修饰键的不算，如 Ctrl+F5 可以设成自定义快捷键）、Ctrl+/ 切换实时渲染 / 源码模式、Ctrl+Shift+1 显示 / 隐藏大纲、Ctrl+W 关闭正显示着的标签、Ctrl+Tab / Ctrl+Shift+Tab 切到下一个 / 上一个标签（这三个对话框里不响应）；在编辑区按住 Ctrl 滚动鼠标滚轮调整正文字号
- 区域切换：Alt+← / Alt+→ 把焦点移到左侧列表 / 右侧（待办正文、项目概览的快速添加框）；Alt+↑ / Alt+↓ 在左侧列表里选中上一项 / 下一项（工作区、项目、待办按显示顺序，折叠起来的跳过），焦点同时移到左侧列表。左侧列表有焦点时，↑↓ 同样上下移动，→ 展开、← 折叠或回到上一级，Enter 打开待办的正文编辑（工作区、项目上是展开 / 折叠）。焦点在正文里时同样生效（正文编辑器不再把 Alt+方向键用于移动行 / 光标）。对话框里不响应；这些组合不能设成自定义快捷键
  - 焦点在右侧、右侧正显示着一条待办（不在批量操作中）时，Alt+← / Alt+→ 改为在标签之间移动：切到左边 / 右边的标签（同点标签，焦点放进正文），在最左边的标签上按 Alt+← 仍回到左侧列表，最右边的标签上按 Alt+→ 仍把焦点放进正文（焦点在标题上时用得着，已经在正文里时不动）；Alt+↑ 关掉正显示着的标签（同 Ctrl+W，按住不放时只关一个，关掉的是最后一个时也不会接着在左侧列表里往上选）；Alt+↓ 仍是在左侧列表里选中下一项。焦点不在左右任何一侧时，按最后获得焦点或用鼠标点过的一侧算：切标签时编辑器重建的一瞬间焦点不在任何地方，仍算在右侧，连着按 Alt+← 不会跳到左侧列表；点了左侧不能获得焦点的地方（列表上方的标题、底部的统计）后算在左侧，Alt+← 回到左侧列表；焦点在弹出的菜单、选择框里时按打开它的那一侧算。右侧显示概览、批量操作时同上面的区域切换
- 编辑快捷键：和上面这些应用快捷键分开，只在待办正文编辑区里生效，两种模式都能用，默认按键与 Typora（Windows）相同（下面列的都是默认按键）。在设置的「快捷键」里单独一组，每条都能修改、恢复默认或不使用，也可以一下全部恢复默认，改了立即生效；所有快捷键（全局、应用内、编辑快捷键和编辑区的固定按键）之间不能重复，录制时当场提示，默认按键已被占用时不能恢复默认。改过的存在设置文件里（只记改过的，没改过的跟着默认值走），随设置一起备份和恢复；设置文件里手改坏的只丢掉坏的那几条；手改成和别的快捷键重复的，设置里标出来并说明实际执行的是哪个，和应用内固定快捷键（如 F5 / Ctrl+R、Ctrl+S）重复的那条不起作用。都只增删选中处的 Markdown 标记，不重排别处的写法；代码块里不做格式、段落操作
  - 格式：Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+U 下划线（`<u>` 标签）、Alt+Shift+5 删除线、Ctrl+Shift+` 行内代码、Ctrl+K 超链接、Ctrl+\ 清除格式。选中的文字（跨行时每行分别看）都已经是这种格式时去掉，否则加上；没选中文字时，光标在这种格式里就去掉它，不在就插入一对标记、光标放在中间。超链接：选中网址时变成 [网址](网址) 并选中前面的文字，选中其他文字时光标放进括号里填地址
  - 段落：Ctrl+1～6 标题 1～6（每级单独设置；已经是这一级时变回正文）、Ctrl+0 正文、Ctrl+= / Ctrl+- 提升 / 降低标题级别（正文 ↔ 标题 6 ↔ … ↔ 标题 1）、Ctrl+Shift+Q 引用、Ctrl+Shift+[ 有序列表、Ctrl+Shift+] 无序列表、Ctrl+Shift+K 代码块；引用、列表、代码块再按一次去掉。Ctrl+T 插入表格（同 Typora 的快捷键，不弹对话框）：插入 3 列、2 行（表头一行加一行内容）的空表格，光标放在表头的第一格；光标所在的行是空行时表格放在这一行，否则放在这一行（光标在表格里时是这个表格、选中了几行时是最后一行）的下面；和上下的文字之间空一行（紧挨着的文字会被当成表格的一行）
  - 缩进：Tab / Ctrl+] 增加缩进、Shift+Tab / Ctrl+[ 减少缩进（Tab、Shift+Tab 是固定的，Ctrl+] / Ctrl+[ 可以改）。光标（选区）在列表项里时，把这一项连同它的子项缩进成上一项的子项 / 提到上一级（列表的第一项不能再缩进，最外层不能再提），有序列表跟着重新编号（原本就不是连续编号的，如全写成 1.，不动）；不在列表里时 Tab 插入两个空格（选中多行时整体缩进）、Ctrl+] 缩进所在的行、Shift+Tab / Ctrl+[ 减少所在行的缩进；列表项里的代码块中同不在列表里。焦点不会因 Tab 跳出编辑区
  - 选择与删除：Ctrl+D 选中当前词（中文按词，同双击）、Ctrl+Shift+D 删除当前词、Ctrl+L 选中当前行（再按往下多选一行）
  - 固定按键（不能修改，设置里只列出来）：列表里的 Tab / Shift+Tab、Ctrl+Z / Ctrl+Y 撤销 / 重做、Ctrl+Enter 跳出代码块、Ctrl+单击打开链接、Ctrl+F / Ctrl+H 查找 / 替换、F3 / Shift+F3 查找下一个 / 上一个

## 设置备份

- 在设置的「备份与恢复」里可以备份到本地，也可以备份到 WebDAV 服务器
- 备份到本地：弹出「另存为」对话框选择保存位置，默认是数据目录（每次都从数据目录打开，可以另选别处），同名文件要确认才覆盖
- 备份到 WebDAV：配置服务器（地址、用户名、密码、远程目录，如坚果云），可以测试连接；远程目录不存在时自动创建
- 备份时把设置文件打包成 zip，文件名包含年月日时分秒（`TodoList-settings-年月日-时分秒.zip`）；备份只含设置（`.settings.json`，快捷键（含编辑快捷键）、主题、字号、编辑区背景色、保存方式、开屏方式、开机自启时是否显示主窗口和快速记录存到哪个项目；开机自启本身不在里面），不含待办数据和密码。本地和 WebDAV 上的备份文件相同，都能用来恢复
- 可以从服务器上的备份列表或本地的备份 zip 恢复设置（选择本地文件的对话框同样从数据目录打开），恢复前要确认；恢复后快捷键（含编辑快捷键）、主题、字号、编辑区背景色和保存方式立即生效（开屏方式、开机自启时是否显示主窗口下次启动时生效），快捷键被其他程序占用时要提示
- WebDAV 密码存在 Windows 凭据管理器，不写进任何文件；访问 WebDAV 时遵循 Windows 系统代理设置，代理例外和 `NO_PROXY` 里的地址直连
